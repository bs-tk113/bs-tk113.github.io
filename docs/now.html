このページの決まり

  • SNS の投稿は転載・翻訳せず、編集部の言葉で事実だけを要約し、元の投稿へのリンクを付けます。
  • 移籍・引退は、本人の投稿とチームの公式発表がそろうまで「確定」と書きません。噂・リークは載せません。
  • 元の投稿が削除されたら24時間以内に要約を外します。公式発表で裏付けがある場合は出典を差し替え、「元の投稿は削除済み」と書きます。
  • スクリーンショット・顔写真・アバター・大会ロゴは載せません。
