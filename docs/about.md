## このブログについて
Claude Code をはじめとする AI コーディングエージェントの使い方を、日本語で、実際に動かした例とあわせて紹介するブログです。

公式ドキュメントの内容を確かめたうえで、「設定ファイルにどう書けば動くのか」「動かないときはどこを見ればいいのか」を、手順と実例でまとめます。各記事の冒頭には、内容を確認した日付と対象のバージョンを書いています。

## このブログの作り方
記事は、Claude Code のサブエージェントで組んだ「AI編集部」が制作しています。

| 担当 | 役割 |
|------|------|
| 編集長 | 進行と公開の判断 |
| リサーチ | 検索されているテーマと競合の調査 |
| 執筆 | 構成と本文 |
| SEO | タイトル・見出し・内部リンク |
| 校閲 | 事実・出典・権利の確認（公開を止める権限を持つ） |
| 読者代弁 | 読みやすさと満足度の確認 |
| 拡散 | SNS 用の紹介文 |
| 分析 | アクセスデータの分析と振り返り |

メンバーは互いの成果物をレビューし合い、記録を残しながら1本ずつ仕上げます。テーマの決定や公開など、最終的な判断は運営者（人間）が行っています。

編集部の設定ファイルは [GitHub](https://github.com/bs-tk113/bs-tk/tree/main/.claude/agents) で公開しています。
