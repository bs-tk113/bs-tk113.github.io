## このサイトについて
{{ site.title }}（かんせんちょう／KANSENCHO）は、日本の VALORANT 競技シーンを「5分で把握する」ための**非公式ファンサイト**です。

速報を追いかけるのではなく、大会の形式、日本チームの道筋、ロスターと移籍、パッチの数値変更を、**表とまとめ**で整理します。すべてのページに最終更新日を書き、公式発表に合わせて更新します。

## 出典ポリシー {#source-policy}
- **一次情報だけを出典にします。** 大会・移籍は公式サイトやチームの公式発表、パッチは公式のパッチノートを確認したうえで書きます。
- **噂・リーク・未確認の情報は載せません。** 「〇〇が移籍か」といった観測記事は書きません。
- **更新日と確認日を明記します。** 記事の冒頭に確認日、ハブ（まとめページ）の一番上に最終更新日時を出します。
- 出典は各ページの「出典」欄に、元のページへのリンクと一緒に書きます。
- 公式の文章をそのまま写すことはしません。数値は表にし、説明は自分たちの言葉で書きます。
- 元の投稿が削除・非公開になったときは24時間以内に要約を外すか、公式発表に出典を差し替えて「元の投稿は削除済み」と書きます。本人・チーム・主催者から削除のご依頼があれば24時間以内に対応します。

## 画像の扱い
- ゲームの画像（エージェント・マップなど）は、VALORANT 公式サイトで公開されているものを、Riot Games の「Legal Jibber Jabber」ポリシーの範囲で使っています。著作権は Riot Games, Inc. に帰属します。
- VALORANT・Riot Games のロゴ、大会ロゴ、選手の写真は使いません。チームのロゴは、チームを見分けるための小さな表示に限り、各チームの公式サイトから取得したものを改変せずに、チーム名と並べて使っています。
- 画像を使ったページには「© Riot Games」の表記と出典を入れています。
- 権利者から削除のご依頼があった場合は、24時間以内に対応します。

## 制作体制
記事は、Claude Code のサブエージェントで組んだ「AI編集部」が下書きと確認を行い、運営者（人間）が最終的に判断して公開しています。

| 担当 | 役割 |
|------|------|
| 編集長 | 進行と公開の判断 |
| リサーチ | 検索されているテーマと競合の調査 |
| 執筆 | 構成と本文 |
| SEO | タイトル・見出し・内部リンク |
| 校閲 | 事実・出典・権利の確認（公開を止める権限を持つ） |
| 読者代弁 | 読みやすさと満足度の確認 |
| 拡散 | SNS 用の紹介文 |
| 分析 | アクセスデータの分析と振り返り |
| デザイン | サイトの設計と表示 |
| ビジュアル | 配色・アイコン・画像 |
