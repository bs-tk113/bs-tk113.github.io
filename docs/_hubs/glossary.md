大会の配信を見ていて「LFT って何？」「エコって負けるつもりなの？」と止まってしまう人のための用語集です。
VALORANT の競技シーンでよく出る**88語**を、**6つの分類**に分けて、それぞれ2〜3文で説明しています。
いちばん下まで読まなくても大丈夫。気になる言葉を、下の「分類から探す」から拾い読みしてください。

## この用語集の使い方

- **分類から探す**: すぐ下のリンクで、大会・チーム・ロール・試合・配信・数値のどこへでも飛べます。
- **関連の用語へ**: 各用語の「関連：」から、意味がつながる言葉へ移れます（例: エコ → フォース → フルバイ）。
- **用語に直接リンク**: SNS などで説明に使うときは、`/hub/glossary/#lft` のように各用語の英字の id（例: #lft、#eco、#kast）を後ろに付けると、その用語の位置が開きます。
- **もっと詳しく**: 「詳しく：」があるものは、このサイトの関連ページ（大会の日程、LFT・FA ボード、eDPI 計算ツールなど）で深掘りできます。

つまり、どういうこと？　を先に言うと、**分からない言葉が出たら、ここで1語だけ引いて配信に戻る**、という使い方を想定しています。

## この用語集の書き方

- **大会の用語は公式に合わせる**: Kickoff・Cups・パートナーなど VCT 2027 の言葉は、VCT 公式の発表（2026年10月30日確認）と、このサイトの [VCT 2027 日程・形式まとめ]({{ '/hub/vct-2027/' | relative_url }}) に合わせています。形式が変わったら、両方のページを一緒に直します。
- **俗語は「一般に」と書く**: ラーカー、ボーナスラウンド、KAST のように、人や統計サイトで意味が少しずつ違う言葉は「一般に〜を指す」と書いています。決まった定義があるような書き方はしていません。
- **数値の計算式は深入りしない**: Rating などの計算方法は表示する場所によって違うため、ACS も含めて、このページでは「何を表す数字か」までにしています。
- **2026年までの言葉も残す**: Stage や Ascension は2027年からなくなりますが、過去の試合を見るときに出てくるので載せています。
