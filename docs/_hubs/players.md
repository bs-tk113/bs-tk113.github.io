## この名鑑で分かること・分からないこと

つまり、どういうこと？　を先に言うと、**「推しの選手が今どのチームにいて、公式にはどう紹介されているか」が分かるページ**です。

| 分かること | 分からないこと（載せないもの） |
|---|---|
| 所属チームと活動名 | 本名・顔写真・アバター |
| 公式に書いてあるロール（例: コーチ、アナリスト、コントローラー） | 公式に書いていないロールや使用エージェント（推測しません） |
| 状態（在籍・チーム募集中・退団発表済み など） | 噂や報道だけの移籍 |
| チーム公式のプロフィールに載っている X・Twitch・YouTube | 公式に載っていない個人アカウント |

ロールの欄が「公式の記載なし」の選手が多いのは、多くのチームが公式サイトにロールを書いていないためです。

## 状態の欄の読み方

| 表示 | 意味 |
|---|---|
| 在籍 | チーム公式サイトの選手一覧に載っている（REJECT はチームの最新のロスター発表に載っている） |
| スタッフ | コーチ・アナリストなど（役割は「ロール・役割」の欄） |
| チーム募集中（LFT） | 本人が X でチームを探していると告知した（退団の発表ではありません）。チーム公式サイトに名前が残っているときは、所属チームの表に載せています |
| 在籍（ロスター外） | チームには在籍しているが、試合に出るロスターには入っていないとチームが発表した |
| 退団発表済み | チームが退団（契約満了・双方合意など）を発表した。発表のあともチーム公式サイトに名前が残っていることがあります |

LFT の詳しい条件は [LFT・FA ボード]({{ '/hub/lft-board/' | relative_url }})、退団・加入の発表日順の一覧は [2027 国内チーム ロスター・移籍トラッカー]({{ '/hub/roster-tracker/' | relative_url }}) で追っています。

## オフシーズンの今、名鑑を見るときの注意

VCT 2027 は、パートナー（Riot と契約したチーム）でも自動で出られるのは年始の Kickoff だけで、それ以外の大会は成績で出場権を取る形（Cups は日本の予選・Playoff を通る）になります。
<!-- 出典: https://valorantesports.com/ja-JP/news/vct-pacific-2027-primer -->

そのため、この秋は各チームが2027年に向けてロスターを組み直す時期です。たとえば DFM は10月29日に、VCT 2027 に向けた選手・コーチ・アナリストの募集を公式サイトで始めています。IGZIST のように、退団の発表のあとも公式サイトに名前が残っている例があります。**「一覧に名前がある＝2027年も残る」とは限りません**。
