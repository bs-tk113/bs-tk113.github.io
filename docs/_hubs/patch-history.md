## このページの使い方

- **パッチ番号から探す**: すぐ下のパッチ番号を押すと、そのパッチの表に飛びます。
- **表の読み方**: 「対象」はエージェント・武器・マップのどれか、「種類」は変更の向きです。
- **数値の書き方**: 「変更前 → 変更後」です。数値は公式どおり、文章は編集部の言葉で短くしています。
- **エージェントごとに追いたいとき**: 表のエージェント名を押すと、[エージェント別 調整履歴]({{ '/hub/agent-history/' | relative_url }}) のそのエージェントの欄に飛びます。

「種類」のラベルは次の意味です。

| ラベル | 意味 |
|---|---|
| 強化 / 弱体化 | 数値や仕様が、使う側にとって有利 / 不利になる変更 |
| 調整 | どちらとも言い切れない変更（スタンを短くしてダメージを足す、など） |
| 新登場 / 作り直し | 新しいエージェント・武器・マップ / マップの大きな改修 |
| プール入り / プール外 | コンペティティブ（ランク）とデスマッチのマッププールに入った / 外れた |

強化か弱体化かは、公式の書き方と数値の向きから編集部が分けたものです。迷うものは「調整」にしています。

### 載せていないもの

不具合修正の細かい項目、スキンなどの見た目、台詞、期間限定モード、Premier の日程は載せていません。競技に関わる変更がなかったパッチも「変更なし」と書いて残しています（抜けと区別するため）。13.03 と 13.07 は公式のニュース一覧に見当たらないため、番号が飛んでいます。

## 2026年のマッププールの動き

コンペティティブ（ランク）とデスマッチのマッププールは、2026年に6回入れ替わりました。

| パッチ（公開日） | 入ったマップ | 外れたマップ |
|---|---|---|
| 13.08（10月13日） | バインド、カロード | アセント、スプリット |
| 13.04（8月18日） | アビス | ブリーズ |
| 13.00（6月23日） | サミット（新マップ）、サンセット | フラクチャー、パール |
| 12.08（4月28日） | アセント | バインド |
| 12.05（3月17日） | ロータス、フラクチャー | アビス、カロード |
| 12.00（1月6日） | ブリーズ（作り直し） | サンセット |

つまり、どういうこと？　を言うと、**1度外れたマップが数か月で戻ってくることが多かった**1年です。カロード（3月に外れ、10月に復帰）、サンセット（1月→6月）、アビス（3月→8月）、バインド（4月→10月）がその例です。

この表は2026年の入れ替えの記録だけから作っています。2025年以前から入っているマップは書いていないので、いまのプールの全体はゲーム内で確認してください。大会で使うマップも、大会ごとの公式発表で確かめるのが確実です。

## 2026年の調整の流れ（ざっくり）

公式パッチノートに書かれた変更と説明から、目立った流れを4つ挙げます。編集部の整理で、強さの評価を断定するものではありません。

1. **6月の 13.00 で、センチネルとイニシエーターをまとめて強化**: センチネル5人（サイファー、キルジョイ、ヴィトー、セージ、デッドロック）と、イニシエーター6人（ソーヴァ、フェイド、スカイ、ブリーチ、KAY/O、ゲッコー）が一度に強化されました。公式は、サイトを守る力と、ラウンド終盤にイニシエーターができることを増やす狙いを説明しています。
   <!-- 出典: https://playvalorant.com/ja-jp/news/game-updates/valorant-patch-notes-13-00 -->
2. **ショットガンとアウトローは弱体化**: 5月の 12.09 でショットガン全種が「動きながら撃つと当たりにくい」方向に、7月の 13.01 でアウトローが「続けて撃つと間が空く」方向に変わりました。アウトローについて公式は、性能が高いことを理由に挙げています。
   <!-- 出典: https://playvalorant.com/ja-jp/news/game-updates/valorant-patch-notes-12-09 -->
   <!-- 出典: https://playvalorant.com/ja-jp/news/game-updates/valorant-patch-notes-13-01 -->
3. **新しい武器が2つ**: 1月の 12.00 で600クレジットのサイドアーム「バンディット」、9月の 13.06 で2,900クレジットのライフル「ウォーデン」が加わりました。どちらもあとのパッチ（13.00、13.09）で強化されています。
   <!-- 出典: https://playvalorant.com/ja-jp/news/game-updates/valorant-patch-notes-12-00 -->

   <!-- 出典: https://playvalorant.com/ja-jp/news/game-updates/valorant-patch-notes-1309 -->
4. **新エージェントが2人**: 3月の 12.05 でミクス（コントローラー）、10月の 13.09 でハッシュ（デュエリスト）が登場しました。
