# サイト設計案（水瀬カナデ / 2026-10-28）

※設計のみ。実装は未着手（ユーザーの了承待ち）。

## 1. 参考サイト（valorantnews.jp）の構造分析
- フロー（ニュース）で毎日来てもらい、ストック（大会ハブ・ツール）で検索と再訪を取る二層構造。ティッカーとサイドバーが全ページで二層をつないでいる
- 学ぶ点: 全ページ共通の試合ティッカー、ツール・人気記事の常設、カテゴリの記事数表示、大会エントリの統一した型、ツールの「入力→結果→共有→解説」
- 上回れる点: ハブに更新日・出典・関連記事がない／ツールに計算式の出典・FAQ・関連記事がない／人気記事の集計期間が書かれていない

## 2. 情報設計
### ページの型
| 型 | 置き場所 | URL | レイアウト |
|---|---|---|---|
| 記事 | `docs/_posts/` | `/:year/:month/:day/:title/` | post |
| ハブ | コレクション `docs/_hubs/` | `/hub/:name/` | hub |
| ツール | コレクション `docs/_tools/` | `/tools/:name/` | tool |
| カテゴリ | `docs/category/*.md` | `/category/<slug>/` | category |

- 手で更新する表データ（試合予定、人気記事、ナビ、カテゴリ）は `docs/_data/*.yml`
- 記事の front matter に `hub:` `tools:` を足して記事末の導線に使う。ハブは `tag:` で関連記事を自動表示

### カテゴリ（1記事1カテゴリ。横断する軸はタグ）
news ニュース／esports 大会・試合／roster チーム・移籍／patch パッチ・アップデート／guide 攻略・ガイド／gear デバイス・設定／skins スキン・ストア／feature 特集・コラム

### トップページ（スマホの縦の並び。PC は右サイドバーへ振り分け）
1. ティッカー（データがない日は出さない） 2. ヒーロー記事 3. 最新記事4件 4. ツール・ハブ帯 5. インフィード広告 6. 人気記事 TOP5（集計期間を明記） 7. 最新記事の続き＋ページ送り 8. カテゴリ一覧（記事数付き）

### 記事ページ
パンくず → ラベル・公開日・更新日 → H1 → リード（対象読者・確認日・対象パッチ） → アイキャッチ → 記事上広告 → 目次 → 本文 → 出典欄（画像クレジット含む） → 更新履歴 → シェア → 記事下広告 → この記事のハブ・ツール → 次に読みたい記事（タグ優先6件） → フッター（免責文）

### ハブページ
パンくず → H1・最終更新日時（必須）・対象期間 → 要点ボックス3行 → 目次 → 構造化ブロック（yml を表・カードに展開） → 日程・結果 → 関連記事10件 → 出典と更新履歴
（大会・パッチまとめ・エージェント一覧・スキン一覧に流用できる）

### ツールページ
入力 → 結果 → 共有（URL で状態を再現） → 計算式と出典（必須） → 使い方と解説 → FAQ → 関連記事。広告は入力の近くに置かない

### ヘッダー・フッター
- スマホ: 1段目（サイト名・検索・テーマ切替・メニュー）、2段目（カテゴリのタブバー。その中だけ横スクロール）、3段目（ティッカー）。下部の固定バーは作らない（アンカー広告と重なる）
- フッター: カテゴリ・ハブ・ツール一覧、運営者情報等、**非公式ファンサイトの免責文（全ページ必須）**

## 3. ビジュアル
- コンセプト「戦術ノート」: 温白色＋インクの紺＋ティールの差し色。赤系・斜めカット・ゲームUI風の装飾は使わない（公式風を避ける）
- 配色トークン（ライト/ダーク）: bg #f7f6f2/#101418、surface #fff/#171c22、fg #1b1f24/#e7eaee、muted #545c66/#a3adb8、accent #0f766e/#2dd4bf、hot #b45309/#f59e0b
- フォント: システムフォント（Web フォントは読み込まない）。文字は全部 16px 以上（今の CSS の .meta / .ad-label / フッターは違反しているので直す）
- 部品: ラベル、ヒーローカード、横長カード、グリッドカード、ツールカード、ランキング、ティッカー、パンくず、リード枠、目次、要点ボックス、スクロール表、出典欄、シェア、ページ送り、チップ、広告枠、免責、ツールフォーム、画像なし記事用の CSS カバー

## 4. 静的サイトでの制約と代替
| やりたいこと | 可否 | 代替 |
|---|---|---|
| 試合スコアの自動更新 | 不可 | `_data/matches.yml` を手で更新。予定と確定結果のみ。過ぎた予定は JS で隠す。最終更新時刻を表示 |
| 人気記事の自動集計 | 不可 | 灰島が週次で GA4 を見て `_data/popular.yml` を更新 |
| サイト内検索 | 可 | Liquid で search.json を作り JS で絞り込み |
| ダークモード切替 | 可 | CSS 変数＋data-theme＋localStorage |
| ツール | 可 | 素の JS＋_data の定数 |
| カテゴリ別のページ送り | 不可 | 最新30件＋年別アーカイブ |
| 自動OG画像 | 不可 | 既定は画像なし（CSSカバー）＋自作の共通OG画像。公式アートは本文の解説に必要な範囲だけ（© Riot Games） |

## 5. 実装手順
1. 土台（_config、_data 雛形、ヘッダー・フッター・免責、配色とテーマ切替）
2. 記事ページ
3. トップ・一覧（ティッカー・人気記事）
4. 検索
5. ハブ・ツールのテンプレート（サンプルは published: false）
6. 360/768/1280px × ライト/ダークで確認
各段階で日向・鳴海・白石がレビュー。変更規模は CSS 約600行、テンプレート・部品 約800行、JS 約350行

## 改訂（2026-10-28 映え重視）

運営者・編集長の判断「画像なし・紙っぽい配色は地味で人が来ない」を受けて、ビジュアル方針を差し替える。情報設計（ページの型・URL・カテゴリ6つ・記事/ハブ/ツールの並び）は変えない。
見本: `drafts/2026-10-28-redesign/mockup/index.html`（単体で開ける。非公開前提）

### GameWith から学んだこと／変えたこと（写さない）
| 学んだ「映え」の作り方 | こちらの形 |
|---|---|
| 上部の大きなキーアート＋サイト名＋検索 | ヒーロー: エージェントの全身アート（透過）を右に、左にキャッチ・検索・よく使う3導線。背景はマップ画像をぼかした上に**自作のグラデーション**（夜色＋金と青緑のにじみ）。GameWith のバナー型ではなく、文字主役の左寄せ＋人物の重ね |
| 大会名のタブ | ヘッダー2段目の「話題タブ」（VCT 2027 / オープン予選 / Pacific 日本勢 / 移籍トラッカー / パッチ履歴 / 5分まとめ / 感度変換）。ロゴは使わず、文字＋カテゴリ色の点。タブ列の中だけ横スクロール |

- システムフォントのまま（Web フォントなし）。最小 16px は維持（ラベル・メタ・広告ラベル・フッター・画像クレジットも 16px）
- ヒーロー見出し clamp(28px, 7vw, 48px)、セクション見出し 22px、カード見出し 17px 太字

### 部品一覧（追加・変更）
追加: ヒーロー（全身アート＋ぼかし背景）、話題タブ、カテゴリ画像タイル、合成サムネ、週まとめカード（要点4行＋カテゴリ色タグ）、画像付きランキング、エージェントアイコン列、ツールカード（入力欄の予告＋計算式の1行表示）
削除: 画像なし記事用の CSS カバー（合成サムネに置き換え）

### 画像の重さ（表示速度対策）
2026-10-28 に実測: エージェント全身像 約614KB、アイコン 約350〜420KB/枚、マップ帯画像 約62KB、マップ全景 約5.2MB（いずれも PNG）。そのままでは重すぎる。
- 見本では、マップ全景は使わず帯画像をぼかして背景にした。アイコン・全身像は外部 URL を直接参照（見本のみ）
- 本番: 入手元が白石の結論で確定したら、自前で縮小・WebP 化して `docs/assets/img/` に置く。目安: 全身像 幅900px・80KB以下、アイコン 96px・8KB以下、マップ帯 30KB以下。ページあたり画像合計 400KB 以内
- ヒーロー画像だけ `fetchpriority="high"`、他は `loading="lazy"`、全 img に width/height を書いてレイアウトのずれを防ぐ
- 外部サイトへの直リンク（ホットリンク）は本番ではしない

### 権利面の扱い（白石の確認待ちの前提）
- 使う: エージェントのアート・アイコン、マップ画像（Riot の「画像はご利用いただけます」の範囲として。最終判断は白石）
- 使わない: VALORANT ロゴ、拳ロゴ、大会ロゴ、チームロゴ、選手写真、公式フォント風の文字。サイトのマークは自作（「仮」の角丸四角。本番は別途作る）
- 画像のあるページには「画像 © Riot Games, Inc.」を表示（ヒーローは右下、記事は出典欄）。フッターに非公式ファンサイトの免責文（全ページ）
