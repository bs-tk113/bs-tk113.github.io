# ビジュアル刷新の方向性（紅林アヤ / 2026-10-30）

運営者の声:「見やすいだけではなく、valorant 感が足りない。アイコン等を充実させたい」
信条:「3秒で『あのゲームのサイトだ』と分かること」。見やすさ（水瀬）は崩さず、熱量と世界観を足す。

## 1. いまの画面の「閲覧者向けでない」ところ（公開中サイトの実箇所）

| 場所 | いま | 何がまずいか |
|---|---|---|
| トップ「最新の週まとめ」 | 「週まとめはまだありません。第1回を準備中です（以後、毎週月曜に公開します）。公開したらここに最新の1本が出ます。」 | 空の箱＋言い訳。読者には何も渡していない |
| トップ「人気ランキング」 | 「集計を始めたら、閲覧数の多いページを週1回更新で表示します（集計期間を明記します）。」 | 運用ルールの説明。右列の一番目立つ場所が空 |
| トップ「新着記事」 | 「まだ記事はありません。最初の記事を準備中です。」 | 同上 |
| トップ「ツール」・各一覧 | 「〜を準備中です。計算式と出典はページ内に明記します。」 | 同上 |
| カテゴリカード | 「公開予定 3本」「準備中」 | 内部の進捗。棚が空に見える |
| 公開予定の一覧（roadmap） | 「企画中」「制作中」「確認中」のタグ | 編集部の工程名がそのまま出ている |
| カテゴリページ | 「このカテゴリで準備しているページです。公式発表を出典に、確認がすんだものから公開します。」 | 運用の説明 |
| /now/ | 「このページの決まり」4項目（24時間以内に外す、等） | 編集部の内規。読者に要るのは「何を信じてよいか」だけ |
| /now/ の各話題 | 「編集部の確認 2026-10-30 01:10」 | 「編集部の」は不要 |
| LFT ボード | 表の下の長い運用注記（削除されたら24時間以内に…） | 内規。要点だけ残す |
| ハブ・ツールの安全装置 | 「最終更新日時が未設定です（front matter の last_modified_at に書いてください）」等 | 万一のとき読者に開発者向けの文が出る |

絵の面: アイコンがゼロ（話題タブは色の点だけ）、エージェント画像は12体・入口は非表示、カテゴリ一覧以外のページ見出しはグラデーションだけ。角丸14pxの白いカードが並ぶだけで、どのゲームのサイトか3秒では分からない。

## 2. どうやって「VALORANT らしさ」を出すか（写さない。雰囲気だけ）

| 要素 | やること | 写さないための線引き |
|---|---|---|
| 配色 | 夜色（#14123a）＋金（#ffb020）は維持。HUD 用の青緑（#5eead4）を罫線・数字に足す | 公式の赤（#ff4655）・生成りは使わない |
| 斜めカットのパネル | カード・カテゴリタイル・タグの角を 1〜2 か所だけ斜めに切る（clip-path） | 白石の NG は「赤＋斜めカット＋公式風書体」の組み合わせ（公式の告知に見える加工）。赤も公式風書体も使わないので組み合わせは成立しない。OG 画像には使わない。**白石の確認を受ける** |
| HUD 風の数字・罫線 | トップのセクション見出しに「01」「02」の等幅番号＋細い罫線＋端の目盛り。件数も等幅の数字 | フォントはシステムの等幅（ui-monospace）。公式フォント・似た書体は使わない |
| ロール色 | デュエリスト 橙／イニシエーター 緑／コントローラー 紫／センチネル 青。必ずアイコン＋ロール名とセット（色だけで伝えない） | 公式のロールアイコンの形は使わず、自作の記号（突撃の三重山形・索敵の波紋・六角の区域・見張りの菱形） |
| エージェント画像 | 全30体の顔アイコン（96px）。トップに「ロール別のエージェント一覧」（絞り込みボタン付き）。合成サムネの右下も斜めカットの枠に | 飾りでばらまかない。一覧は調整履歴ハブ（公開後）への入口を兼ねる |
| マップ画像 | 全13マップ。カテゴリページ・一覧ページの見出し帯の背景にも敷く | ロゴ・文字・透かしの入っていない中央部分だけ |
| アイコン | 自作 SVG スプライト1ファイル（ロール4＋フレックス・IGL・コーチ・選手、カテゴリ7、状態 LIVE/NEW/更新/LFT、ナビ用） | 線画 24px グリッド・currentColor。公式・他サイトのアイコンの形は参照しない |

参考サイトから学んだこと（写していない）:
- GameWith: 画面の上から下までアイコン・画像が途切れない密度 → こちらはアイコンを「タブ・カテゴリ・状態・ロール」の意味のある場所にだけ置いて密度を上げる。白地＋緑の配色・角丸ボタンの形は使わない。
- valorantnews.jp: 見出し帯の熱量とニュースの流れ → こちらは HUD 風の番号見出しと斜めカットで熱量を出す。配色・レイアウトは別物（夜色＋金・右列ランキング）。

## 3. 読者向けの文言の方針
- 「準備中」「公開予定 n本」「企画中」は出さない → 中身がない枠は出さないか、「近日公開」の一語だけ。
- 空のランキング枠は「ピックアップ」（公開済みのまとめ・ツール）に差し替える。
- 運用ルールは「何を信じてよいか」の1〜2行に縮め、全文は運営者情報の出典ポリシーへ。
- 残すもの: フッターの免責文、about.md・privacy.md の必要事項、配信者大会が公式でないことの注記、ツールの「入れた数字はどこにも送られません」。
