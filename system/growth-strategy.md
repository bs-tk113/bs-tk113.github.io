# PV（閲覧数）を増やすための基本戦略

全員がこのファイルを前提に動く。最重要KPIは **PV**。補助KPIは 検索表示回数・CTR・平均掲載順位・記事あたり滞在時間。

## 1. 流入経路と担当

| 流入 | 性質 | 主担当 | やること |
|------|------|--------|----------|
| 検索（Google） | 遅いが積み上がる。本命 | 早瀬・鳴海 | ロングテールKWで上位を取る。記事同士を内部リンクで束ねる |
| SNS（X / Threads / はてブ） | 速いが一過性 | 朝倉 | 公開当日に初速を作る。はてブは技術・生活系に強い |
| 回遊（ブログ内） | 1訪問あたりPVを増やす | 鳴海・日向 | 関連記事・内部リンク・シリーズ化 |

## 2. 記事選びの原則（早瀬）

- **立ち上げ期（〜50記事）はロングテール**: 3語以上の具体的な検索語（例:「〇〇 やり方 初心者」）。大手が書かない細かい悩みを拾う。
- 1テーマを決めたら**クラスター化**: 柱記事1本＋周辺記事5〜10本を内部リンクで繋ぐ。雑記で散らすとどれも伸びにくい。
- 「検索意図」を1文で言えないキーワードは選ばない。
- 季節・ニュース系（瞬発）と、ずっと検索される系（ストック）を **2:8** くらいで混ぜる。

## 3. クリックされる（鳴海）

- タイトルは32字前後、検索語を前半に。数字・具体性・ベネフィットを入れる。
- ただし**中身と違う釣りタイトルは禁止**（直帰が増えて検索順位も落ちる。白石・日向が監視）。
- メタ説明は120字前後で「この記事で何が分かるか」。

## 4. 最後まで読まれる（日向・柚木）

- 冒頭3行で「誰の・どんな悩みを・どう解決するか」を示す。結論を先に。
- スマホ前提。1段落3〜4行まで、見出しごとに要点。表・箇条書き・手順番号を使う。
- 記事末尾に「次に読む記事」を必ず置く（回遊）。

## 5. 育てる（灰島）

- 公開後 **2〜4週** で Search Console を見て、表示回数はあるのにCTRが低い記事はタイトル改善、11〜20位の記事は加筆リライト。
- 新記事だけでなく**既存記事のリライトもPV施策**として週次で枠を取る。

## 6. 広告を後で付けるために今からやること

- プライバシーポリシー・運営者情報・お問い合わせページを用意（済: `docs/privacy.md` ほか）。AdSense審査で必要。
- オリジナルで有用な記事を20〜30本以上、継続更新。コピペ・薄い記事・AIっぽい量産感は審査落ちの原因 → 白石と日向が監視。
- 広告枠はテンプレートに組み込み済み。`docs/_config.yml` に ID を入れるだけで表示される。
