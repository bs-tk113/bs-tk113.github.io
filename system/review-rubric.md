# レビュー書式（全員共通）

レビューは必ずこの形で返す。編集長はこの書式でないレビューを受け取らない。

```
### レビュー: <レビュアー名> → <対象>（<成果物名>）
判定: GO | 要修正 | RED
スコア: <1-5> / 5（観点: <自分の担当観点>）
必須修正:
- [場所] 問題 → 直し方
提案（任意）:
- ...
根拠: <1〜3行。なぜそう判断したか>
```

## スコアの目安

| 点 | 意味 |
|----|------|
| 5 | そのまま出せる。競合上位より明確に良い |
| 4 | 小さな改善点のみ |
| 3 | 公開可能ライン。ただし伸びにくい |
| 2 | 要修正。読者か検索意図を外している |
| 1 | 作り直し |

## 判定の使い分け

- **GO**: 必須修正なし。
- **要修正**: 必須修正があるが方向性は正しい。
- **RED**: 方向性そのものが誤り、または事実・法務・ポリシー上の問題（白石のREDは拒否権）。

## 自己監査の書式（提出物の末尾に付ける）

```
### 自己監査: <名前>
- [x] チェック項目1
- [ ] チェック項目2 → 未達の理由
懸念: <自分で気になっている点。なければ「なし」>
```

「懸念」を正直に書くほど評価される文化にする（隠した問題が後で見つかる方が損）。
